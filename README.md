# App Meteo con Morning Briefing 🌤️

Una Web App full-stack progettata per fornire informazioni meteorologiche e un innovativo servizio di "Morning Briefing" via notifiche push (PWA).

## 🚀 Architettura

- **Backend:** Java 21, Spring Boot 3, PostgreSQL
- **Frontend:** React 18, Vite, TailwindCSS (PWA)
- **APIs esterne:** Open-Meteo

## 📁 Struttura del Progetto

Il progetto utilizza un approccio monorepo:

- `/backend`: API RESTful e Scheduler sviluppati in Spring Boot.
- `/frontend`: Web App React e Service Worker per le notifiche Push.
